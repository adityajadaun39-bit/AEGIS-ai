# AEGIS Community Code of Conduct

## Our Pledge

The AEGIS project is dedicated to providing an inclusive, constructive, and respectful environment for all contributors, researchers, and students.

## Standards of Behavior

- Be respectful and collaborative in code reviews and discussions.
- Welcome differing perspectives and focus on technical merits.
- Prioritize ethical security research and responsible vulnerability disclosure.
- Maintain high integrity in all academic and implementation benchmarks.

## Enforcement

Project maintainers oversee repository conduct and address any non-constructive behavior to maintain a professional engineering standard.
