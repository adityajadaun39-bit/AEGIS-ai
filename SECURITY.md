# AEGIS Security Policy

## Supported Versions

| Version | Supported |
|---|---|
| 1.0.x | Yes |
| < 1.0 | No |

## Reporting Security Issues

If you discover a vulnerability or security bypass in the AEGIS gateway, please report it responsibly:
- Email: `security@aegis-gateway.internal`
- Provide reproduction steps, attack payload, and affected gateway version.
- Please allow 48 hours for acknowledgment before public disclosure.
