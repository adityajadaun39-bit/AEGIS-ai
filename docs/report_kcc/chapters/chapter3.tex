AEGIS operates as an in-line reverse proxy intercepting all tool invocations proposed by an autonomous agent before reaching downstream tools, databases, or network sinks.

The pipeline executes sequentially:
\begin{enumerate}
    \item \textbf{Stage 1 (HMAC Auth):} Validates agent credentials in $<1$~ms.
    \item \textbf{Stage 2 (ML Injection Classifier):} Tier-1 regex heuristics ($<1$~ms) filter known signatures, falling back to Tier-2 ONNX models for borderline inputs.
    \item \textbf{Stage 3 (DLP Scanner):} Regex and Presidio scanners detect sensitive credentials and PII.
    \item \textbf{Stage 4 (OPA Policy):} Evaluates declarative RBAC authorization.
    \item \textbf{Stage 5 (Causal Lineage Tracker):} Verifies session taint and enforces the Provenance Dominance Invariant.
    \item \textbf{Stage 6 (Approval Broker):} Validates cryptographic tokens and dispatches execution inside an isolated sandbox.
\end{enumerate}

\section{Idea Flow \& Conceptual Taint Lineage Architecture}
The foundational thesis of AEGIS resolves the human approval social-engineering trap through causal taint lineage tracking. In conventional Human-in-the-Loop (HITL) frameworks, autonomous agents ingest external untrusted documents (such as PDF resumes, invoices, and support tickets). An attacker embeds an indirect prompt injection within these documents. When the agent processes the file, untrusted data and system instructions intermingle in the attention context, turning the agent into a confused deputy. The hijacked agent crafts a privileged outbound action accompanied by a polite justification (e.g., ``Routine database sync requested by IT''). Deceived by this rationale, a human supervisor approves the request, leading to data exfiltration.

AEGIS eliminates this vulnerability through the \textbf{Provenance Dominance Axiom}:
\begin{quote}
\textit{Data Provenance Strictly Dominates Human Approval. Human authorization is a necessary condition for privileged operations, but never a sufficient one.}
\end{quote}

When untrusted data enters the agent boundary, its session context is permanently labeled as \texttt{UNTRUSTED}. The gateway intercepts outbound tool calls and evaluates their origin lineage. If the lineage DAG contains untrusted data, the gateway enforces the Provenance Dominance Invariant and terminates the request (\texttt{HTTP 403 Forbidden}), overriding any human approval token.

During execution, memory taint accumulates monotonically. Once an agent ingests an untrusted artifact, session integrity transitions irreversibly to \texttt{UNTRUSTED}. Taint cannot be washed away through natural language persuasion or human approval clicks.

\section{System Design Architecture \& Subsystem Interactions}
AEGIS is engineered as an in-line reverse proxy that sits transparently between agent runtimes (such as LangChain, AutoGen, and CrewAI) and external execution environments. It requires zero client refactoring: agents configure the gateway as their base URL or HTTP proxy.

The gateway organizes security verification into a sequential, fail-fast pipeline with strict sub-millisecond to sub-20ms latency budgets. Fast heuristic filtering and authentication reject invalid or malicious requests immediately before activating heavier neural or cryptographic stages.

\begin{table}[htbp]
\centering
\caption{Subsystem Component Matrix and Latency Budgets}
\label{tab:subsystem_matrix}
\begin{tabular}{l l p{5.5cm} c}
\toprule
\textbf{Subsystem Module} & \textbf{Source File} & \textbf{Core Responsibility} & \textbf{Latency Budget} \\
\midrule
Ingress Proxy \& Router & \texttt{app.py}, \texttt{gateway.py} & HTTP proxying \& fail-closed pipeline & $<0.5$~ms \\
Authentication Engine & \texttt{agent\_auth.py} & HMAC-SHA256 agent identity verification & $<0.2$~ms \\
ML Injection Detector & \texttt{ml\_detector.py} & Regex heuristics + ONNX transformer & $0.8 - 14$~ms \\
DLP Scanning Engine & \texttt{dlp\_engine.py} & Secret, key, and PII pattern redaction & $\sim 3.0$~ms \\
Policy Engine & \texttt{policy\_engine.py} & OPA-style YAML access control rules & $\sim 1.0$~ms \\

\bottomrule
\end{tabular}
\end{table}

The subsystem interaction guarantees fail-closed behavior: any parser error, internal exception, or security invariant violation immediately yields an HTTP 403 Forbidden, protecting downstream assets.
