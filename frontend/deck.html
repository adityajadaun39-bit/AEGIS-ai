The Idea Flow: Data Provenance Dominates Approval

Member 3 (Architecture)

1. Traditional Approach: The Approval Trap

• Human is treated as the unconditional root of trust.
• Attacker embeds prompt injection in external data (PDF/Web).
• Agent crafts polite, convincing rationale: "Routine system sync".
• Human clicks [APPROVE] → Secrets exfiltrated!

2. The AEGIS Idea: Provenance-First

• When untrusted data enters, memory context is marked TAINTED.
• Every downstream action inherits the causal source taint.
• Even if human manager clicks [APPROVE], gateway inspects lineage.
• Result: Gateway overrides approval and BLOCKS exfiltration!
